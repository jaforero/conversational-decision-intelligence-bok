# Política de seguridad

## Alcance

Esta política cubre el [portal CDI-BoK](https://decision.javierforero.co/), sus scripts de compilación y publicación, sus dependencias y las exposiciones accidentales de información en este repositorio. Los errores editoriales y de navegación se gestionan en [Issues](https://github.com/jaforero/conversational-decision-intelligence-bok/issues/new/choose).

## Reporte privado

1. Usa **Security → Report a vulnerability** si GitHub muestra esa opción. Si el formulario no está disponible, usa el [contacto público del mantenedor](https://cv.javierforero.co/#contacto) por un canal privado.
2. Incluye la URL o ruta afectada, el tag o SHA, el impacto potencial y pasos mínimos para reproducirlo con datos sintéticos. Evita publicar detalles en issues, pull requests o comentarios.
3. Si encuentras una credencial o dato sensible, indica su ubicación y tipo. Omite el valor y los archivos que lo contienen.

El mantenedor revisa el alcance y coordina la corrección y la divulgación según el caso.

## Datos en contribuciones

Usa ejemplos sintéticos, agregados autorizados o fuentes públicas cuya reutilización esté documentada. Revisa adjuntos, capturas, metadatos y archivos generados antes de incluirlos en un commit.
